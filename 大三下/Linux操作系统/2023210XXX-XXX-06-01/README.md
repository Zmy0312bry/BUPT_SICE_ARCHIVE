# 单词统计
## 统计标准
只统计由**字母组成**的完整单词（如 `the`、`packet`、`header`），排除包含数字、标点或特殊字符的"非纯词"（如 `IPv6`、`RFC-2460`、`v6`、`6lowpan` 等）。



## 管道逐级分析

### 完整管道（省略重定向等内容）

```bash
cat rfc2460.txt \
  | tr -s '[:space:]' '\n'      # Step 1
  | tr -d '[:punct:]'            # Step 2
  | grep -E '^[a-zA-Z]+$'       # Step 3
  | tr '[:upper:]' '[:lower:]'   # Step 4
  | sort                         # Step 5
  | uniq -c                      # Step 6
  | sort -rn                     # Step 7
  | head -30                     # Step 8
```

---

### `tr -s '[:space:]' '\n'`

**作用**：将所有空白字符（空格、制表符、换行等）压缩替换为单个换行符。

- `-s`：压缩重复字符
- `[:space:]`：匹配所有空白字符（空格、`\t`、`\n`、`\r`、`\f`、`\v`）
- `'\n'`：目标替换字符为换行符

**示例**：

```
输入: "Hello World\nThis is IPv6"
输出:
Hello
World
This
is
IPv6
```

---

### `tr -d '[:punct:]'`

**作用**：删除所有标点符号。

- `-d`：删除
- `[:punct:]`：匹配所有标点字符，包括 `!` `"` `#` `$` `%` `&` `'` `(` `)` `*` `+` `,` `-` `.` `/` `:` `;` `<` `=` `>` `?` `@` `[` `\` `]` `^` `_` `` ` `` `{` `|` `}` `~`

**示例**：

```
输入: "Hello,"
      "World!"
      "state-of-the-art"
      "RFC-2460"
      "IPv6"

输出:
"Hello"
"World"
"stateoftheart"
"RFC2460"
"IPv6"
```

> 注意：`state-of-the-art` 中的连字符被删除后变为 `stateoftheart`（三个词被合并为一个）；`RFC-2460` 变为 `RFC2460`；`IPv6` 保持不变（数字和字母都在）。

---

### `grep -E '^[a-zA-Z]+$'`

**作用**：只保留**完全由字母组成**的行（一个或多个大小写字母）。

- `-E`：启用扩展正则表达式
- `^`：行首
- `[a-zA-Z]+`：一个或多个大小写字母
- `$`：行尾

**示例**：

```
输入:
"Hello"       → ✅ 通过（纯字母）
"World"       → ✅ 通过
"stateoftheart" → ✅ 通过
"RFC2460"     → ❌ 过滤（含数字）
"IPv6"        → ❌ 过滤（含数字）
""            → ❌ 过滤（空行，不满足 +）

输出:
Hello
World
stateoftheart
```

> `IPv6` 不会被拆成 `ipv` 片段，而是被整个丢弃。`RFC-2460` 也不会被拆出 `rfc`。这保证了统计结果中的每个"单词"都是在原文中由纯字母构成的真实词汇（或删除标点后合并成的字母串）。

---

### `tr '[:upper:]' '[:lower:]'`

**作用**：将所有大写字母转换为小写字母，实现大小写不敏感统计。

- `[:upper:]`：匹配所有大写字母 `A-Z`
- `[:lower:]`：匹配所有小写字母 `a-z`

**示例**：

```
输入: "Hello"
      "WORLD"
      "StateOfTheArt"

输出:
"hello"
"world"
"stateoftheart"
```

---

### `sort`

**作用**：按字典序对所有单词进行排序。

---

### `uniq -c`

**作用**：统计重复行的出现次数。

- `-c`：在每行前加上出现次数

**示例**：

```
输入:
hello
hello
world

输出:
      2 hello
      1 world
```

> `uniq` 只统计连续的重复行，因此必须在它之前用 `sort` 排序。

---

### `sort -rn`

**作用**：按出现次数从高到低排序。

- `-r`：反向排序，默认升序，加 `-r` 后变降序
- `-n`：按数值大小排序，而非字典序

**示例**：

```
输入:
     10 hello
    155 the
      5 world

输出:
    155 the
     10 hello
      5 world
```

---

### `head -30`

**作用**：只取前 30 行，即频率最高的 30 个单词。
