# 内核源码下载

## 题目要求

### 基础要求

1. 不指定参数时，给出 usage
2. 参数 -q：列出网上可下载 Linux 内核源码清单（版本号）
3. 参数 -d xxx -i yyy：下载指定版本内核源码到指定目录
4. 下载途中以百分比方式显示下载进度
5. 只下载 xxx.tar.gz 文件

### 进阶要求

1. **版本校验**：下载前验证版本号是否存在，不存在时给出可用版本列表建议
2. **断点续传**：支持 -r 参数从上次中断处继续下载
3. **多版本管理**：
	- 维护已下载版本列表（存于 ~/.kernel_manager/db）
	- 支持 -l 参数列出本地已下载的内核版本
	- 支持 -c 参数清理指定版本
4. **完整性校验**：下载完成后使用 SHA256 校验文件完整性
5. **并发下载**：支持 -j N 参数启用 N 个并发连接加速下载
6. **下载限速**：支持 -s speed 参数限制下载速度（如 500k、2m）
7. **通知功能**：下载完成或失败时发送桌面通知（使用 notify-send）
