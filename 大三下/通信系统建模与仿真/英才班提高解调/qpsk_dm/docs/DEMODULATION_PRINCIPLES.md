# QPSK 解调关键部分原理说明

---

## 1. 输入加载：uint8 → complex128

`.dat` 文件存储的是 `uint8` 类型 IQ 采样，值域 [0,255]，而非标准复数信号。`mat2dat` 转换时使用的正向映射为：

```
uint8 = clamp(round((val + 1.0) × 127.5), 0, 255)
```

零点恰好映射到 128。接收端逆变换：

```
complex = (I - 127.5) / 127.5 + 1j × (Q - 127.5) / 127.5
```

除以 127.5（而非 128）是为了保证幅度范围的精确对称性。I/Q 分量交替存放（IQIQIQ…），偶数索引为 I，奇数索引为 Q。

后续所有 DSP 算法（FFT、滤波、相关）均基于浮点复数运算，且需要正确的幅度标度。

---

## 2. 去直流

零中频接收架构中，本振泄漏 (LO Leakage) 和 ADC 直流偏置会在基带信号中引入直流分量：

```
samples_dc_free = samples - mean(samples)
```

直流分量表现为 IQ 平面上一个固定的复数偏移。若不消除：

- 在 FFT 频谱 0 Hz 位置产生尖锐谱线
- 当实际频偏接近 0 时，直流谱线可能被误认为信号谱线，干扰四次方法的频偏估计
- 对后续相关运算也有负面影响

---

## 3. 载波频偏估计与矫正（四次方法）

### 动机

发射端和接收端本振频率不一致，存在载波频偏 Δf。频偏导致接收符号在 IQ 平面上持续旋转，未经矫正无法正确判决。

### 四次方消除调制

QPSK 符号位于相位 {π/4, 3π/4, 5π/4, 7π/4}。四次方后四个相位全部映射到 -1，调制信息被消除：

```
(exp(j·π/4))⁴ = (exp(j·3π/4))⁴ = (exp(j·5π/4))⁴ = (exp(j·7π/4))⁴ = -1
```

剩余分量仅包含频偏（放大为 4 倍）：

```
x[n]⁴ = A⁴ · exp(j·4·2π·Δf·n/fs + jφ₀)
```

### 频谱寻峰

对 x[n]⁴ 做 FFT（加 Hanning 窗抑制频谱泄漏），最强谱线对应 4Δf：

```
f_peak = argmax(|FFT(x⁴ · hanning)|)
Δf = f_peak / 4
```

### 复数旋转矫正

```
samples[n] = samples[n] · exp(-j · 2π · Δf · n / fs)
```

每个采样点乘以对应时刻的逆向旋转因子，消除频偏产生的累积相位。

不矫正频偏 → 星座图持续旋转 → 无法硬判决 → BER 急剧恶化。

---

## 4. RRC 匹配滤波

### RRC 冲激响应

发射端使用根升余弦 (RRC) 滤波器对离散符号做脉冲成型。其时域冲激响应为：

```
            sin(πt(1-α)/T) + 4αt·cos(πt(1+α)/T)
h_RRC(t) = ────────────────────────────────────────
                  πt(1 - (4αt/T)²)
```

其中 α 为滚降系数（决定带宽超出 Nyquist 带宽的比例），span 为时域跨度（以符号计），T 为符号周期。

### 匹配滤波

在白噪声条件下，接收端使用与发射脉冲共轭匹配的滤波器，使采样时刻输出信噪比最大化。

### 级联特性

```
发射 RRC + 接收 RRC = 升余弦 (RC) 总响应
```

RC 满足 Nyquist 第一准则：在采样时刻 t = ±T, ±2T, ... 处响应为零，相邻符号对本符号的干扰为零（ISI 消除）。发射/接收滤波器均能量归一化以保幅度一致性。

---

## 5. 最佳采样点选择

输入信号 sps=4，每个符号周期内有 4 个采样点。将滤波后序列按 4 相位分解：

```
branch_0 = filtered[0::4]    branch_2 = filtered[2::4]
branch_1 = filtered[1::4]    branch_3 = filtered[3::4]
```

每条分支对应符号周期内不同的采样时刻。

对每条分支计算与已知 63 符号 preamble 的归一化互相关。相关峰最大值对应的分支即为最佳采样相位。选择 preamble 相关峰作为判决标准的原因：preamble 是唯一在同步前已知的信号段，其相关峰直接反映该相位下信号与期望符号的匹配程度——相关峰越高，该采样时刻信号质量越好。

错误采样相位 → ISI 未完全消除 → 星座点发散 → 误符号率上升（可达数 dB 的 SNR 损失）。

---

## 6. 前导码同步检测

### 归一化互相关

采用 Pearson 相关系数形式的归一化互相关：

```
          |Σ r[m+k] · conj(p[k])|
ρ[m] = ─────────────────────────────
        √(Σ|r[m+k]|² · Σ|p[k]|²)
```

分子为非归一化互相关，分母为两序列能量的几何平均。ρ ≈ 1 时检测到帧头，ρ ≈ 0 时不匹配。归一化使检测对信号幅度波动不敏感。

### 峰值检测参数

- **height = 0.75**：低于此阈值不可能是帧头
- **distance = 100 symbols**：帧头间最小间距，防止脉冲噪声伪峰
- **prominence**：要求峰相对于周围足够突出

### 多相位融合与时钟漂移

4 个相位分支分别找峰，按样本位置聚类。同一帧的 preamble 可能在多个分支上均有相关峰，聚类后每簇保留最强的一个。

发射和接收采样时钟存在微小频率差（ppm 级），长时间采集下眼图中心可能从一个相位分支滑到另一个。因此，**不为全局选定统一相位，而是为每一帧独立从 4 个分支中选择**。

帧起始位置错误 1 个符号 → 所有后续解码全错，前导码同步是整个接收机的核心。

## 7. 帧长估计与组数 (burst_time) 计算

### 帧长估计

```
diffs = diff(frame_starts)                           // 所有相邻峰间距
median_diff = median(diffs)                           // 中位数
valid = diffs[|diff - median| ≤ max(2, 0.02×median)]  // 剔除异常
frame_length = round(mean(valid))                     // 采样点
syms_per_frame = frame_length / sps                   // 符号数
```

使用中位数抗异常峰，异常值剔除边界为最大(2, 2%中位数)。

### burst_time 计算

根据帧格式定义：
- 每组字符数 = base_data_len + 3(编号) + 1(换行)
- 每组数据符号 = 组内字符数 × 4（每字符 = 4 QPSK 符号）
- 每组导频数 = 组内字符数（每 4 数据后插 1 导频，恰好每字符后插 1 导频）
- 每组总符号 = 组内字符数 × 5

```
burst_time = (syms_per_frame - 63) / 每组总符号
```

其中 63 为 preamble 占据的符号数。帧长和组数是后续阶段的必要参数——没有组数，就无法确定导频在帧内的分布位置。

## 8. 导频辅助信道估计与补偿

### 动机

无线信道引入的幅度衰落和相位旋转是时变的。前导码仅能估计帧头的信道状态，无法覆盖帧尾。导频均匀分布于整帧（每 4 数据符号后插入 1 个参考符号），可以跟踪信道随时间的变化。

### 单抽头信道估计

在每个导频位置，直接计算复数信道增益：

```
h[k] = received_pilot[k] / known_pilot[k]
```

假设信道在一个符号周期内近似平坦（窄带假设），单抽头即可描述。

### 线性插值与补偿

实部和虚部在导频已知点间分别做分段线性插值，获得连续信道响应 h[n]：

```
h_all[n] = interp(n, pilot_positions, h_pilots)
corrected[n] = received[n] / h_all[n]
```

除以复数信道增益同时补偿幅度衰落和相位旋转。若信道变化较快（高多普勒），导频间距决定了可跟踪的最高变化频率。

## 9. QPSK 解映射与文本恢复

### Gray 映射硬判决

相邻象限仅差 1 bit（Gray 码特性），最小化误符号造成的误比特数：

| 象限 | 条件 | 比特 | 符号 |
|------|------|------|------|
| I | I ≥ 0, Q ≥ 0 | 00 | 1+1j |
| II | I < 0, Q ≥ 0 | 01 | -1+1j |
| III | I < 0, Q < 0 | 11 | -1-1j |
| IV | I ≥ 0, Q < 0 | 10 | 1-1j |

### 比特重组与文本提取

```
每 4 个 QPSK 载荷符号 = 8 bit → 1 个 ASCII 字符
```

跳过每第 5 个位置的导频符号。解码后用正则表达式从字符串中提取 `basedata` 部分。

---

## 10. 误码率 (BER) 统计

### base_data 推断

从多帧解调文本中正则提取 `basedata + 三位数字`，按出现次数做多数投票：

```
base_data = argmax(计数)
```

跨帧投票对单帧误码具有鲁棒性。

### BER 计算

```
期望文本 = base_data001\n + base_data002\n + ... (共 burst_time 组)
期望比特 = ASCII 编码 → 逐位 0/1 序列
误比特数 = Σ |received_bit[i] XOR expected_bit[i]|
BER = 误比特数 / 总比特数
```

若无法从解调数据可靠推断 base_data，则不能计算 BER（缺乏参考比特序列），此时给出警告而非伪造数值。BER 是系统性能的最终量化指标，反映从加载到解映射整个链路的累计误差影响。

## 设计原则总结

| 原则 | 体现 |
|------|------|
| 先矫正后判决 | 频偏矫正 → 匹配滤波 → 定时 → 信道补偿 → 判决 |
| 已知信号驱动 | preamble 驱动同步，导频驱动信道估计 |
| 统计鲁棒 | 中位数抗异常峰，多数投票抗误码 |
| 时钟漂移容忍 | 每帧独立相位选择，不假设全局统一相位 |
